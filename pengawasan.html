Apakah RINTIK sendiri masih layak dipercaya?

Kalau RINTIK memeriksa sensor, RINTIK juga harus diperiksa. Unggah satu CSV 90 hari: sistem menilai kesehatan harian (Trust Score), mengaudit akurasi terhadap kelembapan referensi, lalu memberi rekomendasi beserta alasannya.

Pemeriksaan Sensor Pengawasan 90 Hari
Trust ScoreKesehatan operasional harian: kualitas input (Q), pergeseran input (D), pipeline (P), kewajaran output (O). Bukan akurasi.
Audit akurasiP3 yang diterbitkan dibandingkan dengan kelembapan referensi terverifikasi. Hanya audit yang menilai akurasi.
KeputusanDihitung backend dari angka-angka itu. Melatih ulang model tidak pernah dijalankan otomatis.

Unggah dataset 90 hari

CSV berisi waktu, 24 kolom sensor lingkungan, nilai P3 RINTIK per 30 menit, catatan teknis pipeline, dan RH referensi beserta status verifikasinya. Kolom di luar skema (mis. label atau skor jadi) ditolak. File tidak disimpan.
